# 全局 UX 提升设计文档 — "零培训"目标

> 版本: 0.2.0 | 日期: 2026-09-21 | 状态: Phase 0~6 已实施
>
> 实施节奏：task-agent v3 后端能力完成后统一实施

---

## 1. 背景与目标

### 1.1 当前问题

墨方 v0.6.0 后端能力已达到 76 分，但前端 UX 存在系统性问题：

- **Emoji 当图标** — 全部用 emoji 代替 SVG 图标，跨平台渲染不一致
- **操作无文字** — 按钮只有图标没有文字标签，不悬浮不知道含义
- **状态不可见** — 关键信息（工作目录、模式、处理状态）不在列表中显示

### 1.2 目标

> **"零培训"** — 用户无需阅读文档或培训，打开软件就能理解每个按钮的含义和操作方式。

## 3. 分模块诊断与方案

### 3.1 首页 (HomePage)

**现状**:
- 服务状态卡片用 ✓/✗ 字符，视觉弱
- 快速入口用 emoji 图标（💬📚📊）
- 最近活动列表用 emoji 图标（💬📁）

**问题**:
- 状态卡片缺乏色彩区分（正常=绿、异常=红），纯文字 ✓✗ 不够醒目
- 快速入口卡片不够大、不够吸引，没有引导感
- "产业洞察" 入口名称抽象，新用户不理解含义

**方案**:
- 状态卡片：正常用绿色圆点 + "正常"，异常用红色脉冲圆点 + "异常"
- 快速入口：放大卡片尺寸，用 Lucide 图标 + 简短描述
- 最近活动：hover 显示操作按钮（打开/删除）

---

### 3.2 对话/洞察 (Chat/Insights)

**现状**:
- ConversationList: "+ 新建对话" 按钮清晰
- ConversationItem: ✏️🗑️ 操作按钮
- ChatView/MessageInput: ■➤ 发送/停止

**问题**:
- ConversationItem 的 ✏️🗑️ 不悬浮不知道含义
- MessageInput 的 ■ 停止按钮不够直观（用户可能不知道方块=停止）
- 对话没有搜索功能（对话多了找不到）

**方案**:
- ConversationItem: hover 显示文字按钮 "重命名" "删除"
- MessageInput: 停止按钮改为 "停止" 文字
- 考虑增加对话搜索（Ctrl+F 在侧栏搜索）

---

### 3.3 知识库 (Knowledge)

**现状**:
- ProjectList 在侧栏，创建/删除/重命名
- KnowledgePage 主区域：文件管理 + 搜索 + 图片 + AI 问答
- 功能丰富但入口较深

**问题**:
- 知识库页面功能密度高，新用户可能不知道从哪开始
- 文件状态（待处理/解析中/完成/错误）用文字标签，不够醒目
- "AI 问答" 按钮藏在底部

**方案**:
- 空项目状态增加引导："上传文件开始使用" + 支持格式说明
- 文件状态用彩色圆点/标签（灰=待处理，蓝=解析中，绿=完成，红=错误）
- "AI 问答" 按钮位置提升或增加快捷键

---

### 3.4 任务 (Tasks) — 问题最多

**现状**:
- `TaskList.tsx`: `[+ 新建任务] [📂]` 两个按钮
- `TaskItem.tsx`: 只显示标题+消息数+时间，操作是 📦📁📂✏️🗑️
- `TaskPage.tsx`: 顶栏 `🛠 编程 ⇄ | 📋 | 📁`
- `TaskChatView.tsx`: 输入区 `[📎] ... [⏸] [■]` 或 `[📎] ... [➤]`
- `TaskMessageList.tsx`: 工具图标全 emoji，状态用 ✅❌

**问题**（按严重度排序）:
1. 📂 按钮含义不明 → 用户不知道是"选目录新建"
2. 任务列表不显示工作目录 → 不知道任务在操作什么
3. 顶栏全是 emoji → 不知道能干什么
4. 输入区按钮无文字 → 不知道含义
5. 确认弹窗用 emoji → 不够严肃
6. 工具卡片状态用 ✅❌ → 视觉噪音大

**方案**:
- 新建按钮 → 下拉菜单（"默认工作区" / "选择目录新建"）
- TaskItem → 显示目录名（最后2级）+ 模式标签（编程/通用）
- 顶栏 → 文字按钮（"编程模式 ▾" "日志" "文件"）
- 输入区 → 文字按钮（"附件" "发送 →" "暂停"）
- 确认弹窗 → 颜色区分按钮 + 进度条倒计时
- 工具卡片 → 彩色圆点状态（绿=成功，红=失败，蓝脉冲=运行中）

---

### 3.5 设置 (Settings)

**现状**:
- 左侧导航 + 右侧内容
- 返回按钮用 `←` 字符
- 整体比较干净

**问题**:
- `←` 返回按钮太简陋，可以用 SVG 箭头
- 部分设置项缺乏说明（如"Temperature"对普通用户太专业）
- 没有搜索设置项功能

**方案**:
- 返回按钮用 Lucide ArrowLeft 图标
- 增加设置项搜索（Ctrl+F 在设置页搜索）
- 专业参数增加 "什么是?" 提示

---

### 3.6 全局布局 (TitleBar/Sidebar/NavTabs)

**现状**:
- TitleBar: 菜单式（文件/编辑/视图/帮助）+ 窗口控制
- Sidebar: NavTabs 在底部（🏠💬📚🛠📊）
- ResizeHandle: 拖拽调整宽度

**问题**:
- NavTabs 在底部不够显眼，且用 emoji
- 侧栏折叠/展开按钮在 TitleBar 右上角，不容易发现
- 没有全局快捷键体系

**方案**:
- NavTabs 图标换 Lucide SVG
- 考虑增加全局快捷键：Ctrl+1~5 切换导航
- 侧栏折叠增加明显提示（如 hover 边缘显示）

## 5. 统一交互模式

### 5.1 列表项操作（ConversationItem/TaskItem 统一）

```
默认状态:
┌──────────────────────────────┐
│ 标题                          │
│ 元信息（时间/消息数/目录）      │
└──────────────────────────────┘

hover 状态:
┌──────────────────────────────┐
│ 标题              [重命名] [删除] │
│ 元信息                          │
└──────────────────────────────┘
```

- 操作按钮用文字，不用 emoji
- 删除用红色文字
- 悬浮时从右侧滑入

### 5.2 确认弹窗统一样式

```
┌─────────────────────────────────────┐
│ [图标] 标题                    ████░░│  ← 进度条倒计时
│ ┌─────────────────────────────────┐ │
│ │ 内容（代码块/描述）               │ │
│ └─────────────────────────────────┘ │
│                                     │
│ [主要操作]  [次要操作]     [取消]    │  ← 颜色区分
└─────────────────────────────────────┘
```

### 5.3 状态指示统一

| 状态 | 视觉 | 颜色 |
|------|------|------|
| 成功/正常 | 实心圆点 | `#22c55e` (绿) |
| 失败/错误 | 实心圆点 | `#ef4444` (红) |
| 运行中/处理中 | 脉冲圆点 | `#2563eb` (蓝) |
| 等待/待定 | 空心圆点 | `#9ca3af` (灰) |
