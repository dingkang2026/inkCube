# UI 设计 — Chat 模块

> 版本: 0.1.0 | 日期: 2026-09-14 | 状态: 初始设计

## 1. 整体布局

三栏结构：左侧边栏 + 中央聊天区 + 右侧设置面板（可收起）。

```
┌──────────────────────────────────────────────────────────────────┐
│  ┌──────────┐  ┌──────────────────────────────┐  ┌───────────┐  │
│  │          │  │                              │  │           │  │
│  │  侧边栏   │  │        聊天区域               │  │  设置面板  │  │
│  │          │  │                              │  │  (可选)   │  │
│  │  260px   │  │        自适应宽度              │  │  320px    │  │
│  │  可折叠   │  │                              │  │  可收起    │  │
│  │          │  │                              │  │           │  │
│  └──────────┘  └──────────────────────────────┘  └───────────┘  │
└──────────────────────────────────────────────────────────────────┘
```

**响应式断点:**
- `>= 1200px`: 三栏全展开
- `>= 768px`: 侧边栏可折叠，设置面板浮层
- `< 768px`: 侧边栏全屏覆盖，单栏切换

### 1.1 可调整面板宽度

侧边栏和设置面板均支持通过拖拽分隔条自由调整宽度。

```
┌──────────┬┐  ┌──────────────────────────────┐  ┌┐───────────┐
│          ▓│  │                              │  │▓          │
│  侧边栏   ▓│  │        聊天区域               │  │▓  设置面板  │
│          ▓│  │                              │  │▓          │
│  可拖拽 → ▓│  │        自适应宽度              │  │▓ ← 可拖拽  │
│          ▓│  │                              │  │▓          │
└──────────┴┘  └──────────────────────────────┘  └┴───────────┘
             ↑ 分隔条 4px                        ↑ 分隔条 4px
             hover 时高亮                         hover 时高亮
```

**约束:**

| 面板 | 最小宽度 | 最大宽度 | 默认宽度 |
|------|----------|----------|----------|
| 侧边栏 | 200px | 480px | 260px |
| 设置面板 | 280px | 520px | 320px |

**交互细节:**
- 分隔条默认 4px 宽，透明
- hover 时显示 2px 宽的主题色指示条（居中）
- 拖拽中 cursor 全局锁定为 `col-resize`，防止鼠标脱离分隔条
- 双击分隔条恢复默认宽度
- 拖拽过程中聊天区域自适应填充剩余空间

### 2.1 交互细节

**会话项右键菜单 / 悬停操作:**

```
┌────────────────────┐
│ ✏️  重命名          │
│ 📋  复制最后一条回复  │
│ 🗑️  删除           │
└────────────────────┘
```

**删除确认:** 点击删除后，会话项变为确认状态，3 秒内可撤销。

```
┌────────────────────────┐
│ 删除"关于量子计算的讨论"？│
│ [撤销]     [确认删除]    │
└────────────────────────┘
```

**重命名:** 点击重命名后，会话标题变为 inline 输入框，Enter 确认，Esc 取消。

**新建对话:** 点击 `+` 立即创建空对话并切换到聊天区域，焦点自动落入输入框。

**折叠态:** 侧边栏折叠后仅显示一个窄条（48px），包含折叠按钮和新建按钮。

```
┌────┐
│ ☰  │
│    │
│ ＋ │
│    │
└────┘
```

### 4.1 设置项说明

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| API 地址 | 文本输入 | `https://api.openai.com/v1` | 兼容 OpenAI 格式的端点 |
| API Key | 密码输入 | 空 | 存储于本地加密存储 |
| 模型名称 | 文本输入+下拉 | `gpt-4o` | 支持手动输入自定义模型名 |
| Temperature | 滑块 | 0.7 | 范围 0-2，步长 0.1 |
| Max Tokens | 数字输入 | 4096 | 范围 1-128000 |
| Top P | 滑块 | 0.9 | 范围 0-1，步长 0.05 |
| 系统提示词 | 多行文本 | 空 | 全局 system prompt |

### 4.2 设置存储

- 配置保存于 `%APPDATA%/InkCube/config/settings.json`
- API Key 使用 Electron 的 `safeStorage` 加密后存储
- 修改后点击"保存配置"生效，不自动保存（防止误操作）
- "测试连接"发送一个简单请求验证配置有效性

## 6. 状态管理

```typescript
// 全局 Store 结构

interface AppState {
  // 会话
  conversations: Conversation[]
  activeConversationId: string | null
  
  // 消息（按会话分组）
  messages: Record<string, Message[]>
  
  // 生成状态
  isGenerating: boolean
  currentStream: StreamState | null
  
  // 设置
  settings: LLMSettings
  
  // UI
  sidebarCollapsed: boolean
  settingsOpen: boolean
}

interface Conversation {
  id: string
  title: string
  created_at: string
  updated_at: string
  message_count: number
}

interface Message {
  id: string
  conversation_id: string
  role: 'user' | 'assistant' | 'thought' | 'action' | 'observation'
  content: string
  metadata?: {
    tool_name?: string
    tool_input?: object
    tool_output?: string
    tokens?: number
    duration_ms?: number
  }
  created_at: string
}

interface LLMSettings {
  api_url: string
  api_key: string
  model: string
  temperature: number
  max_tokens: number
  top_p: number
  system_prompt: string
}

interface StreamState {
  conversation_id: string
  message_id: string
  content: string
  thoughts: string[]
  actions: ActionState[]
}
```

## 9. 数据流

### 9.1 发送消息

```
用户输入 → ChatInput.onSend
  → store.sendMessage(conversationId, content)
    → ipcRenderer.invoke('chat:send', { conversationId, content })
      → Main Process → HTTP POST /chat (SSE)
        → Python Agent 处理
          → SSE events → Main Process → IPC → Renderer
            → store.appendStream(event)
              → MessageList 自动滚动到底部
              → 渲染 Thought / Action / Answer
```

### 9.2 加载历史

```
侧边栏点击会话 → ConversationItem.onClick
  → store.setActiveConversation(id)
    → ipcRenderer.invoke('conversations:get', id)
      → Python: SELECT * FROM messages WHERE conversation_id = ?
        → 返回消息列表
          → store.setMessages(id, messages)
            → MessageList 渲染
```

### 9.3 会话管理

```
新建:  store.createConversation() → IPC → Python INSERT
重命名: store.renameConversation(id, title) → IPC → Python UPDATE
删除:  store.deleteConversation(id) → IPC → Python DELETE
列表:  store.loadConversations() → IPC → Python SELECT (按 updated_at DESC)
```

## 10. 边界情况

| 场景 | 处理方式 |
|------|----------|
| API Key 未配置 | 设置面板自动打开，提示配置 |
| 网络错误 / Python 崩溃 | 消息区域显示错误提示 + 重试按钮 |
| 消息过长 | 代码块横向滚动，长文本正常换行 |
| 空对话列表 | 侧边栏显示引导："点击 + 开始新对话" |
| 生成中断开连接 | 已生成内容保留，显示"连接中断"提示 |
| 快速连续发送 | 生成中禁用输入框，显示排队状态 |
| 会话标题过长 | 单行截断 + tooltip 显示完整标题 |
