## 1. 产品定位与四支柱

### 1.1 客户工作模型（设计依据）

两类客户日常工作同构（工作全景表见 2026-10-23 设计评审记录），每份工作都有明确承载面：

| 招商经理 | 投资经理 | 本质（支柱） | V2 承载 |
|---|---|---|---|
| 扒线索 / 盯竞品园区 | 扫赛道 / 盯竞品基金 | ① 情报（撒网+盯梢） | 情报中心（一级导航）+ 首页情报卡片区 |
| 推项目节点 / 盯已落地企业 | 推进尽调交割 / 盯条款投后 | ② 项目生命周期 | 项目·事务 Tab + 脉搏带 + 首页投资组合卡片墙 |
| 摸底尽调 / 读月报对数 | 尽调比对 / 读被投企业月报 | ③ 知识册（去伪存真、可阅读） | 项目·知识 Tab（阅读优先重构） |
| 周报月报 / 填系统表 / 汇报 PPT | 投决材料 / LP 季报 / 董事会 PPT | ④ 产出效率 | 项目·产出 Tab（报告+填表+PPT）+ 任务模板 |

价值链：**找（情报）→ 跟（生命周期）→ 懂（知识册）→ 交（产出）**，一切围绕项目展开：
情报是项目的输入，知识册是项目的记忆，交付物是项目的输出，生命周期是主线。

### 1.2 情报中心与任务的关系（关键澄清）

一句话：**任务是「派活」，情报是「委托」；订阅 = 任务 × 周期节奏，情报中心 = 订阅产出的阅读与管理面。**

| 关系 | 内容 | 状态 |
|---|---|---|
| 生产（任务→情报） | 每条期次 = 一次后台任务的产出（影子任务）；订阅 = 模板 prompt + 周期 + 去向；期次「执行过程」回放 = 任务工作区 | 已有 |
| 孵化（任务→订阅） | 任务模板「设为订阅」；对话经 `schedules:refinePrompt` 提炼为订阅 | 已有 |
| 消费（情报→任务） | 线索「转跟进任务」（复用 `tasks:create` + 预填）；期次产物自动沉淀绑定项目 | 转任务为 V2 新增交互（已拍板）；沉淀已有 |
| 边界 | 情报中心不做任务管理（运行看板在任务 Tab/首页进行中区）；任务页不做期次阅读；两个 Tab 共享同一执行引擎、模板库、活动中心 | 设计约束 |

心智：同一台引擎，手动挡（任务）与自动挡（情报）两个驾驶舱。

## 3. 分面重设计（现状 → 目标）

### 3.1 首页 = 晨会简报

| # | 区块 | 现状 | 目标 | 数据源（零新增） |
|---|---|---|---|---|
| ① | 今日概览条 | 4 统计卡 | 保留 | dueData + useActivity |
| ② | **情报卡片区** | 情报速览在侧列、5 行小列表 | **上移主列顶部**，卡片网格（auto-fill）：卡 = 要点标题 + 订阅名 + 类别 chip + 相对时间 + 状态点 + 未读点；点击→阅读页；「查看全部」→ 情报 Tab；零订阅 = 空态引导「新建订阅」 | `schedules:digest` |
| ③ | 今日待办 + 近期日历 | 有 | 保留（空态占位惯例不变） | dueData |
| ④ | 项目卡片墙 | 健康+下一事务+台账摘要+新产出角标 | **E3 升级「投资组合仪表盘」**：+ 阶段进度（STAGE_MAP）+ AI 脉搏句行（`pulse_ai_status` 随 projects 流）+ 矛盾/缺口计数行（healthByProject） | 全部现有派生 |
| ⑤ | 侧列：动态流 + 快捷动作 | 两张动作卡 | 保留 + **第三卡「新建订阅」**（→ 情报中心订阅管理） | — |

早晨动线：扫情报（②）→ 排今天（③）→ 盯盘子（④）。

### 3.2 情报中心（新一级页）

- 结构：页头（标题 + 「新建订阅」主钮）+ 子 Tab（**情报流** / **订阅管理**）。
- **情报流**：类别筛选 chips（`全部 / 盯企业 / 产业线索 / 竞品 / 其他`，由订阅模板类别前端常量映射派生，i18n）+ 跨订阅期次卡片流（**未读优先**、finished_at 倒序、`limit/offset/has_more/total` 分页 + 加载更多）。卡片：要点标题（`run.summary[0]`）+ 订阅名 + 类别 + 相对时间 + 状态点（running 呼吸 / failed 红）+ 未读点；done/failed 点击 → 阅读页；running → 订阅管理。
- **订阅管理**：现 `SubscriptionAdminView` 整体迁入（订阅列表 / 新建编辑模态 / 运行历史 / 归档重建 / 熔断态），**组件级复用非重写**。
- 徽章：`schedules:summary.total` 未读数（挂载 + 终态边沿，零新增轮询）。

### 3.3 情报阅读页（ReadView 增强）

保留全部现状能力（摘要卡 / Markdown 全文含来源节 / Ctrl+F 块级查找 / 执行过程回放 / 订阅设置 / 沉淀跳转 / 失败重跑），新增：

- **「转跟进任务」按钮**（头部动作条）：
  - 点击 → `tasks:create`（默认工作区，与「发送即建任务」同链）→ 选中新任务 → 输入框预填 prompt：`# {期次标题}` + 要点 + 跟进指令模板 → 跳任务页（**不自动发送**，模板是半成品 prompt 原则）。
  - 创建失败（含配额 409）toast 反馈，停留原页；输入内容不丢失。
  - 零新增后端：`tasks:create` 第三消费方 + 现有预填机制。

### 3.4 项目页 = 脉搏带常驻 + 四 Tab

| 层 | 现状 | 目标 |
|---|---|---|
| 脉搏带 | 常驻顶部（AI 句 + chips + 建议入口） | 保留，定位升级为「项目健康总览」 |
| Tab | `wiki / affairs / materials / reports / forms` 五个 | **`事务 / 知识 / 产出 / 素材` 四个** |
| 事务 | AffairsTab（时期看板/周期节奏/日历） | **置首**，原样迁位 |
| 知识 | WikiTab（6 视图平铺） | 阅读优先重构（§3.5） |
| 产出 | reports（已含 PPT 区块）与 forms 两个 Tab | 合并：Tab 内二级分区「报告 / 填表」（PPT 居报告分区）；头部「模板管理」直达钮（入口前移，BaseLibFooter 原入口保留） |
| 素材 | materials | 原样迁位 |

- ⚠ **显式翻转 3.0「知识置首」决议**（用户认可 2026-10-23）：四支柱排序生命周期 > 知识；知识关键信号已由常驻脉搏带 chips 承载，知识 Tab 无「错过感」。
- 叙事：素材（原料）→ 知识（加工出真相）→ 产出（交付）+ 事务（主线推进）。
- `tabSignal` 兼容：`'forms'` → 产出 Tab + 填表分区锚点（一个版本周期内兼容旧信号）。

### 3.5 知识册（WikiTab V2：一本书 + 幕后编辑部）

**阅读层（默认）**：

| 区 | 现状 | 目标 |
|---|---|---|
| 封面（home 改造） | purpose/overview 编辑 + 按 page_type 平铺索引 + 待编译提示 + 完成度 | **项目故事页**：overview + purpose + **结构完成度环** + **目录卡片组**（语义分组）+ **信任信号行**（矛盾 N / 缺口 N / 待编译 N，reviewsCounts+pendingCompile 已有；全 0 不渲染） |
| 目录（左栏改造） | 按 page_type 平铺 | **语义分组**：跟踪（`is_ledger=1` 台账页，**置顶**）/ 画像 / 实体 / 概念 / 来源；组内页数徽标；未编译结构页置灰 |
| 台账页阅读 | 台账=普通 Markdown 页 | **时间轴原生渲染**（`wiki:listLedgerEntries` 按 entry_date 分组，复用 3.1 时间轴卡模式；无条目回落原文渲染） |
| 搜索 / 图谱 | 平铺视图 | 收为阅读工具条入口（视图组件保留） |
| 沉浸阅读 | 有 | 保留 |

**整理层（收纳，不重写）**：左栏底部「整理」分组（计数徽标）——编译（CompilePanel）/ 健康检查（Lint 治理工作台）/ 结构页（Schema 管理）/ 时间线（changelog）。现四视图组件原样收纳；lint/compile 直达信号（`wikiFocus`）路由不变。

导航形态：`6 视图平铺` → `阅读 3 入口（封面/搜索/图谱）+ 整理 4 面板分组`。

### 3.6 任务页

- 工作区 / 模板欢迎页现状保留（0.5 E1/E2 已产品化）。
- 侧栏 TaskList 头部新增「订阅」图标钮 → 情报中心·订阅管理（孵化动线：这次查企业 → 以后定时盯它）。

### 6.2 状态-界面映射（关键页）

### 6.3 关键交互规则与不变量

1. 打开期次即已读（现状规则 10 保留，仅 done 态）。
2. 转跟进任务：创建失败 toast 留原页；成功跳任务页并预填、**不自动发送**（模板=半成品原则）。
3. 情报流分页契约 `limit/offset/has_more/total`（[0.1](0.1dev-guide.md) §16）；「未读优先」是默认视图语义，关闭筛选即时间倒序。
4. 项目四 Tab 顺序不变量：事务恒第一；产出含「报告/填表」两分区，PPT 留报告分区。
5. 目录「跟踪」组以 `is_ledger` 为唯一判定（3.1 §3.4 同源）；分组只改呈现不改 page_type 语义。
6. 整理层四面板为现组件收纳，逻辑不重写；`wikiFocus`（lint/compile）直达路由不回归。
7. 全部新文案双语 i18n；0.3 token 体系沿用；**零新增轮询**（徽章=挂载+终态边沿，同 IntelDigest 现模式）。
