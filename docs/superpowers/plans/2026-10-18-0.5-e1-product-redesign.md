# 0.5 产品化整改 E1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 0.5 文档 E1 期——首页重排（移除服务4卡/概览条/异常横幅/快捷动作化）、任务欢迎页模板化（10 条 i18n 内置模板）、项目欢迎页三步引导、项目 toggle 显式取消守卫。

**Architecture:** 纯前端变更，零新表零新 IPC。首页健康态沿用现有 `system:getHealth` 一次拉取（消费方式从卡片改为横幅）；模板走 i18n JSON 常量 + 前端正则解析；引导卡复用 `knowledge:createProject` 与 `PROJECT_TYPE_CONFIG`。

**Tech Stack:** React 18 + TypeScript + Vite；vitest（组件测试，与被测文件同目录）；i18next（zh-CN/en-US 双 JSON）。

**Spec:** `docs/0.5product-redesign.md`（§4 整改设计 / §6 数据流 / §7 前端交互 / §8 E1 验收）。交互以该文档文字设计为准（原型已废弃删除，2026-10-18）。

## Global Constraints

- 零新表、零新 IPC 通道；`node dev/_orphan_channel_audit.js` 四组必须为 0。
- 门面文案禁系统词（LLM/VLM/Embedding/执行代码等，0.5 §4.1）；全部新增文案 zh-CN/en-US 同步落地。
- 模板点击只预填不自动发送；占位符未填齐发送不禁用，但首次点击 toast 提示一次（0.5 §7.3）。
- 「显式取消」不变量：侧栏点已选项目取消选中后，同一导航会话内自动选中不得顶回；切 NavTab 或重新选择后守卫复位（0.5 §7.3）。
- 进行中/待办/日历保持「空即隐藏」现状（0.5 §7.3）。
- **git 操作由用户手动执行**：各任务的 commit 步骤实施者只做暂存清单核对，不执行 git 命令。
- 每任务完成即验证：`npx tsc --noEmit` → 相关 vitest → 最终统一 `npm run build` + 全量测试。
