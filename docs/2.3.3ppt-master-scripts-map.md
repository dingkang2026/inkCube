# 2.3.3 ppt-master 脚本地图（240 个 py 全量角色与消费面）

> 定位：`resources/skills/ppt-master/scripts/` 全部 **240 个 py**（157,285 行）+ 16 子包 + 非 py 数据资产的角色地图，回答「哪个脚本在哪个环节被谁调用、InkCube 要不要碰」。md 文档地图见 [2.3.2](2.3.2ppt-master-docs-map.md)；集成契约（环境变量/参数/产物）见 [2.3.1](2.3.1ppt-master-integration-reference.md)。
> 证据：`scripts/README.md`（官方索引权威，11 组 Area 表）逐节研读 + 240 py 全量清点（2026-10-16 实测）+ 未索引脚本在包内 md 中的提及归位。

## 1. 总览与组织规律

- **规模**：240 py / 157,285 行 = **顶层散布脚本 73 个（48,882 行，含薄壳入口与内部支撑）+ 14 个 py 子包（108,403 行）**；另有两个非代码目录（`assets/` 静态资产、`docs/` 深文档）。
- **官方索引权威** = `scripts/README.md`（Area 表 11 组）；每组的深文档在 `scripts/docs/`（16 篇，见 2.3.2 §L10）。
- **命名规律**（README §Recommendations 明文）：每个工作流在 `scripts/` 顶层只留一个用户入口（如 `finalize_svg.py` 507 行入口 → `svg_finalize/` 8 文件实现）；provider 实现/内部 helper 一律进子目录。入口脚本普遍是薄壳（20-80 行），重逻辑在子包。
- **审计链**：`project_manager.py init` 之后，项目内 CLI 自动把命令信封与有界结果写入 `<project>/validation/workflow.log`（不复制控制台全流）——InkCube 的任务日志解析对象（2.3.1 §7）。

全包非 md 资产统计（打包视角）：

| 类型 | 数量 | 主要位置 | 定性 |
|---|---|---|---|
| .svg | 12,185 | 以 `templates/icons/` 图标库为主体 | 数据资产（E1 icon_sync 的同步源） |
| .wav | 186 | `templates/sounds/` | 音效库（sound_sync 消费） |

| .json | 17 | 4 类模板索引 + `pptx_animation_presets.json` + `prompt_audit_manifest.json` 等 | 索引/预设（审计清单不进 prompt 上下文） |
| 其他 | txt 5 / js 2 / html 2 / css 2 / .example 1 / xml 1 | 包根与 confirm_ui | 配套 |

## 4. InkCube 消费面汇总

### 4.1 E1 Generate 直接调用集（按执行顺序）

1. `attribution_guard.py`（启动墙）
2. `confirm_ui/server.py --daemon --no-browser --timeout 0`（Gate 1/Gate 2；门毕 `--shutdown`）
3. `project_manager.py init / import-sources`（+ `page-context` 诊断）
4. `source_to_md.py`（源导入）/ `icon_sync.py`（图标池门）
5. `image_gen.py` / `image_search.py`（图片三路径之二；AI 生成路径为 executor 内嵌）
6. `notes_to_audio.py` → `narration_sync.py`（音频链；one-shot 配置后）
7. `total_md_split.py` → `finalize_svg.py` → `svg_quality_checker.py`（后处理+质检门）
8. `svg_position_calculator.py`（仅图表页 verify-charts）
9. `svg_to_pptx.py`（导出；`--no-notes` / `--recorded-narration` / `--native-charts-and-tables` / `--image-sizing` 按需）
10. `pptx_animations.py` / `pptx_transitions.py` / `sound_sync.py`（可选动画）
11. `powerpoint_video.py --check` → 导出 → `video_sound_mix.py` / `video_subtitles.py`（可选视频）
12. `svg_editor/server.py --daemon` + `check_annotations.py`（live-preview 编辑环）
13. `pptx_delivery_check.py`（交付检查）

### 4.2 E2 模板管理调用集

`pptx_template_import.py` → `svg_authoring_view.py` → `extract_svg_assets.py` / `extract_svg_pictures.py` / `compact_svg_coordinates.py` →（mirror 模式）`mirror_template_materialize.py` → `template_preview_pptx.py`（Review PPTX）→ `register_template.py`（入库唯一通道）。

### 4.3 E3 Enhance 调用集

`native_enhance_pptx.py init / plan / validate / apply`（核心在 `native_enhance_pptx_core.py`）→ 音频复用 `notes_to_audio` / `narration_sync` → `pptx_animations.py` / `pptx_transitions.py` → `pptx_delivery_check.py`。

### 4.4 排除集（不调用、不暴露、不打包裁剪对象另议）

`prompt_audit.py`（维护者审计）、`update_repo.py`（仓库自更新）、`generate_examples_index.py`、`latex_render.py`（legacy）、`native_narration_pptx.py`（legacy）、`chart_recall.py`（legacy）、`template_fill_pptx.py` 全链（暂不暴露，2.3 §4.4）、3 个 smoke 文档对应的临时项目命令。

### 4.5 环境变量面对接（详见 2.3.1 §6）

- 图片：`IMAGE_BACKEND` + 各后端 key（`.env.example` 为形态参考；CWD `.env` 注入）
- 图搜：`IMAGE_SEARCH_*` 前缀（web 路径需网络 + 候选审查）
- TTS：后端 key 经 `notes_to_audio.py` 读取
- 全局配置解析集中在 `config.py`——InkCube 凭据注入只需对准该文件的读取约定
