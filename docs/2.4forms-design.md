# 填表系统功能设计文档

> 版本: 0.1.0 | 日期: 2026-09-26 | 状态: 规划中（本阶段不实施）
>
> 核心定位: 结构化数据填充，与报告系统并列的产出形式

---

## 1. 背景与定位

填表是墨方项目系统的**第二种产出形式**，与报告系统并列。

**核心区别：**

| 维度 | 报告系统 | 填表系统 |
|------|---------|---------|
| **产出形式** | 自由文本（长文） | 结构化数据（表格） |
| **内容特征** | 分析性、论述性 | 数据性、清单性 |
| **输出格式** | Word/PDF | DOCX 表单 / XLSX |
| **生成方式** | LLM 按章节生成 | 从知识库提取数据填充 |

### 预置填表模板

| 表格名称 | 适用项目类型 | 输出格式 |
|---------|------------|---------|
| 项目登记表 | 招商引资 | DOCX 表单 |
| 招商跟踪表 | 招商引资 | DOCX 表单 |
| 政策申报表 | 招商引资 | DOCX 表单 |
| 尽调清单 | 投资分析 | DOCX 表单 |
| 投资决策表 | 投资分析 | DOCX 表单 |
| 估值对比表 | 投资分析 | XLSX |
