# 填表系统设计

> **概述**：填表系统是项目的**第二种产出形式**，与报告系统并列——报告输出自由文本长文，填表输出结构化数据（从知识库提取字段值填充表单/表格）。该功能**后端尚未实施**：当前仅有 UI-First 原型（`FormsTab.tsx`，挂载于项目详情页），模板、表单实例、字段值全部为组件内置 mock，无后端路由、无 IPC 通道、无落库、无真实导出。本文档承载实施前需确定的设计决策。项目页对填表 Tab 的现状描述见 [2.1 §10](2.1project-design.md)。

## 1. 定位：与报告系统的对比

| 维度 | 报告系统 | 填表系统 |
|------|---------|---------|
| 产出形式 | 自由文本（长文） | 结构化数据（表单 / 表格） |
| 内容特征 | 分析性、论述性 | 数据性、清单性 |
| 输出格式 | docx / pdf（[2.5](2.5report-design.md)） | DOCX 表单为主，少量场景 XLSX |
| 生成方式 | LLM 按章节生成 | 从知识库检索提取字段值填充 |
| 引擎形态 | 独立多步流水线（report_generator） | 待定（提取链路可复用检索引擎） |

## 2. 现状：UI 原型（FormsTab.tsx）

项目详情页「填表」Tab（`src/features/project/tabs/FormsTab.tsx`）已实现完整交互骨架，三视图状态机 `list → filling / preview`：

| 视图 | 内容 | 数据来源 |
|------|------|---------|
| list | 模板选择区（chip 列表，按项目类型过滤：general 全量，招商/投资仅显示对应类型）+ 「我的表单」实例卡片（状态角标 completed / filling） | 内置 mock：模板 7 个、实例 3 个 |
| filling | 选择模板后进入：提取进度动画（200ms×10 假进度）→ 完成后字段编辑（label + input 逐项可改）→ 确认导出按钮 | mock 字段值（3 组模板有演示数据，其余回落通用字段） |
| preview | 打开已有表单实例：字段编辑 + 导出 | mock 字段值 |

导出动作为 `alert` 提示（`t('project.forms.exportSuccess')`），无文件产出。UI 文案已走 i18n（`project.forms.*`）；mock 模板名与字段值为硬编码中文（落地时需一并清理，已在 [2.1 §13.2](2.1project-design.md) 登记）。

原型内置的 mock 模板清单（7 个）：

| 模板 | 适用项目类型 | 格式 |
|------|------------|------|
| 项目登记表 / 招商跟踪表 / 政策申报表 / 企业经营跟踪表 | 招商引资 | DOCX |
| 尽调清单 / 投资决策表 | 投资分析 | DOCX |
| 估值对比表 | 投资分析 | XLSX |

## 3. 实施前需确定的设计点

以下四项是立项时必须先回答的设计问题：

1. **填表模板结构**：模板元信息（名称 / 适用项目类型 / 输出格式）+ 字段定义（字段类型、数据来源、提取提示词）。需与报告模板系统（[2.5](2.5report-design.md)）决策模板存储与校验机制是否复用；自定义模板支持导入 / 导出分享。
2. **数据提取策略**：从项目知识库（含关联基础库）自动提取字段值——检索（复用 [2.2 §6](2.2knowledge-base-design.md) 混合检索引擎）+ LLM 提取 + 置信度 / 来源标注；提取为长时活动时须接入统一活动模型（[0.4 §3](0.4lifecycle-design.md)），不自建轮询。
3. **填表流程**：选择模板 → 自动提取（进度反馈）→ 用户预览 / 逐字段编辑 → 导出；表单实例的落库表与生命周期（草稿 / 完成、重开再编辑、删除级联）需按设计文档三要素补全表结构。
4. **导出格式**：DOCX 表单（python-docx，已在依赖内）与 XLSX 表格（openpyxl，引入前按依赖管理规范评估打包兼容性）。

## 4. 差异与下一步建议

### 4.1 文档与代码差异

无——后端未实施，本文档 §2 如实描述原型现状，§1 / §3 为前瞻设计。

### 4.2 实施路径建议

按能力递进分五步，每步可独立交付：

1. **模板加载**：预置模板落为真实资源（`resources/templates/` 分发机制见 2.1 §11.3），替换 mock 清单。
2. **数据自动提取**：接检索引擎 + LLM 提取，替换假进度动画。
3. **DOCX 表单导出**：真实文件产出与保存路径选择。
4. **XLSX 表格导出**：表格类模板（估值对比表等）。
5. **自定义模板管理**：创建 / 编辑 / 导入导出分享，表单实例历史管理。
